Calendar Studio — Theme Preset Library

Eight additional template directions, each a distinct visual identity rather than a palette swap. Built to sit alongside the six existing StudioThemes (jade, lacquer, indigo, saffron, mono, night) and the seven base templates already in template_library.dart.

Every preset below is both a rendered mock-up and a machine-readable spec — read on for the schema.

For coding agents implementing these as StudioTemplates: each <section class="preset"> below carries a <script type="application/json" class="spec"> block with the exact design, in the same shape as the Dart block model — type matches BlockKind (calendarGrid, text, image, logo, eventList, holidayLegend, shape, decoration), bounds is [x,y,w,h] as 0–1 fractions matching NormRect, and colors are either a ThemeRole name (resolved against the preset's own palette, given in theme) or a literal "#RRGGBB". The rendered card next to it is the same layout at the stated canvas preset, for visual reference — read the JSON for exact numbers, not pixels off the screenshot.
canvas.preset → one of a4_portrait, a4_landscape, a3_portrait, square, story (existing CanvasSpec presets)
theme → new hex values per role; not yet a StudioThemes entry — add one
blocks[].type: "decoration" with "newMotif": true → motif isn't in DecorationMotif yet; add it + a path builder like stupa_path.dart
blocks[].type: "shape" → maps straight to ShapeBlock, no new enum needed
category → suggested TemplateCategory (wall/desk/print/annual/social/story)
referenceMonth → the month shown in the mock-up (September 2026, for apples-to-apples comparison); the template itself is month-agnostic
