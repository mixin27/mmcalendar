Calendar Studio · tools v3

A redesign of how you edit in Calendar Studio. Select anything and its most-used controls appear right beside it. Double-tap text to type straight onto the page. Every property the renderer supports gets a control. A project has one theme you can switch in a tap. All the settings that shape a project live on one Project settings screen. Screens use the Rose Bond preset for January 2027, in Clear (iPhone, web) and Material (Android).

1 · Editing model

Three layers, each one tap deeper. You never open a settings sheet just to type a word or change a colour.

1. On the pageTap to select, drag to move, handles to resize and rotate. Double-tap text to type in place. Pinch to zoom, two fingers to pan.
2. Contextual barShows above the selection with the 4–6 controls you use most for that element, for example Font, Size, Colour and Align for text. Each opens a small popover right there.
3. InspectorThe bar's ••• button opens everything else: a sheet on phones, a docked panel on tablets and desktop. Tabs are Content, Style and Layout. Layout always has exact X, Y, W, H and rotation.
Theme firstColour pickers lead with the project's theme roles (Paper, Primary, Accent, Ink, Muted, Holiday, Sabbath), then recent colours, then Custom. Elements that use a role follow the theme when it changes.

2 · Text

Double-tap, type, done. The keyboard pushes the bar up so it stays in view. One typing session is one undo step. Text bound to the month or year says so and offers "Custom text" to override it.

3 · Image and logo

Replace, crop and fit without leaving the page. Crop happens on the canvas, with the full photo dimmed around the frame.

4 · Shapes and decorations

Decorations (rings, lotus, borders, motifs) become first-class elements you can add, recolour with theme roles and swap.

5 · Calendar grid

The grid's bar covers what you change most: which marks each day shows, the week start, the style and the colours. Every colour role the preset uses is editable, and a change can apply to this month or all twelve.

6 · Event list and holiday legend

Both get controls for the first time: which events or marks to show, how many and how they look.

7 · Canvas

Select several elements to move, align or style them together. Layers can be dragged to reorder and renamed. Everything you can drag also has a button.

8 · Add

One Add panel with tabs. Text comes as ready styles, calendar parts are their own tab, and what you used last is first.

9 · Project settings

One screen for everything that shapes the whole project, replacing the setup sheet, the Calendar settings sheet and the grid's Data tab. New projects use the same groups as a three-step setup: Calendar, Theme, Format.

10 · Page

Background, print margins and the pages themselves.

11 · Layouts

Phone: canvas, contextual bar and a five-tool dock. Tablet (600–1023 px): canvas with the inspector docked on the right and layers in a drawer. Desktop (1024 px+): tool strip, layers, canvas, inspector and a page strip.

Choices built into these screens that you may want to change.
